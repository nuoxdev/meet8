# Meet8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Adapt Desk8 Connect into an independent organization-branded meeting application.
**Architecture:** React/Vite frontend and Fastify API backed by PostgreSQL, using extracted Desk8 LiveKit call components. Server-enforced organization membership and verified email identity govern all privileged operations.
**Tech Stack:** TypeScript, React, Fastify, PostgreSQL, LiveKit, Node test runner, Playwright.
**Spec:** ../specs/2026-11-08-meet8-design.md

## Global Constraints
- Only the platform owner creates organizations and assigns managers.
- Public registration never grants organization membership.
- Copy and adapt Desk8 Connect source; do not copy data, credentials, or unrelated modules.
- Independent sessions, database, configuration, and LiveKit namespaces.
- Open-link guests require a name; invited-only access requires verified invited email.
- Do not claim live calls, email, DNS, or deployment without real verification.

## Review Focus
- Revocation during active or reconnecting calls must invalidate privileged access.
- Expired/replayed email challenges must never establish a session.
- Concurrent starts/restarts must produce one active meeting session.
- Switching organizations must never expose cached records from another tenant.
- Bad provider settings and network failures must produce actionable errors.
